How to read these views

C1 shows people and external systems. C2 shows runnable applications and local file stores. C3 expands logical components inside the client, server and shared library.

The client and server each contain their own copy of shared_lib code and world state. A library is not a deployed C4 container. Blue boxes represent internal elements; gray boxes represent people or external systems. These diagrams show selected architectural relationships rather than every import.

Runtime boundaries

Local gameplay and the integrated editor execute within the client. Online matches use an authoritative server with client prediction and reconciliation. Native networking uses GameNetworkingSockets; browser builds use a WebRTC bridge with optional server support. The server registers metadata with an external lobby over HTTP. Developers can inspect movement with the optional native scenario player.

Maintaining this documentation

Update these views when process boundaries, component responsibilities or simulation contracts change. Each page links to its source evidence. The diagrams are inline SVG and also provided as standalone files. All styling is local and pages support browser printing.
