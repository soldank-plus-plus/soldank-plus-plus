Scope and behavior

WorldTickInput and WorldTickResult form the explicit simulation boundary: commands and player inputs enter; SimulationEvent values leave. Networking adapters use the shared protocol but the world tick does not require a transport. Communication protocol is a sibling component used by client and server networking, not a simulation subsystem called by World.

Simulation callers

  • The client uses the world loop with callbacks for input and presentation. The server runs its own fixed-timestep loop and supplies selected inputs and commands to the world each tick.

Movement scenario components

ScenarioCatalog provides built-in definitions. ScenarioRunner drives shared soldier movement with scripted inputs, and ScenarioExport handles loading and exporting scenario JSON. The desktop player uses client rendering to display the results. Movement tests can use the scenario library directly. Scenario library modules · Scenario runner
