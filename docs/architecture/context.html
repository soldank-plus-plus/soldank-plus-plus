C1 · System context

Soldank++ in its environment

The system includes the game client, integrated map editor, game server and optional movement scenario tooling. The lobby is an external service; libraries and build tools are not separate software systems.

Scope and behavior

Local play and map editing can run without a remote game server. Online play connects a client to a server. The lobby relationship is server registration. Developers use the standalone movement scenario player to reproduce and inspect movement behavior without connecting to a server.

User workflows

  • Players run a local match or connect a client directly to a game server for online play.
  • Map authors edit and play-test a map in the same client.
  • Server operators configure a headless match server. The server sends registration metadata to the configured external lobby.
  • Developers run predefined or saved movement scenarios and inspect or export the results.
